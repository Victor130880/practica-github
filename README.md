##Documentacion
GitHub es una plataforma que permite almacenar, compartir y colaborar en 
proyectos software utilizando el sistema de control de versiones Git. Git es
un sistema de control de versiones distribuido.
Los tipos de repositorios se clasifican principalmente por su visibilidad,
por ejemplo hay públicos, privados e internos.
